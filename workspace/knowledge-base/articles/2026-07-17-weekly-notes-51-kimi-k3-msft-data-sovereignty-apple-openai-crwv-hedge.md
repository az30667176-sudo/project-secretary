# KP 週記 51:Kimi K3 / 微軟賣盾 / 蘋果阻擊 OpenAI / CoreWeave 對沖記憶體

## Summary

FOMO研究院 KP 週記第 51 期(2026-07-17)以「電子報點閱率下滑是精準反向指標」開場,主張市場大跌時研究 ROI 反而指數上升。核心大主題是中國月之暗面發布的 **Kimi K3(2.8 兆參數 MoE、100 萬 token 上下文)**,多項評測進全球前四且將於 7 月底完全開源權重,KP 判定這是「首款在特定場景硬碰硬的中國旗艦」而非單純價格破壞,但實測話癆問題讓「每美元有效智慧」成為更準確的比較指標。作者以**傑文斯悖論**駁斥「AI 支出將減少」的論述:token 價跌不會讓企業省錢,而是把省下的成本塞進更多場景,推理算力需求反而爆發,加上軍備競賽領跑者壓力與雲端巨頭 credits 閉環供血兩個機制。微軟則靠 Nadella 的「逆向資訊悖論」與 **Frontier Tuning**(早期客戶 token 效率提升約 10 倍)重新定位為「既賣矛又賣盾」的系統平台;蘋果對 OpenAI 提告聚焦「模型為王 → 系統層為王」的終端入口之爭。文末揭露 CoreWeave 正研議買入美光/SK 海力士個股賣權對沖長約價格下限風險,是週期末端的額外壓力訊號。

## Key Takeaways

- **Kimi K3 是首款硬碰硬的中國旗艦**:2.8 兆參數 MoE、100 萬 token 上下文,多項評測全球前四,7 月底完全開源權重;但「話癆」問題使實際任務成本接近 GPT-5.6 Sol。
- **傑文斯悖論駁斥支出減少論**:token 價跌不會讓企業省一半,而是塞進以前不敢用的場景(多模型路由、Agent 自我糾錯),推理算力需求反而爆發。
- **微軟「既賣矛又賣盾」**:Frontier Tuning 早期客戶(Land O'Lakes)token 效率提升約 10 倍,從代幣銷售升級為系統平台,削弱所有模型廠商的談判籌碼。
- **蘋果起訴 OpenAI**:聚焦 io Products 收購與挖角案,本質是「模型為王」轉向「系統層為王」的終端入口之爭。
- **CoreWeave 對沖記憶體風險**:研議買入美光/SK 海力士個股賣權,對沖長約價格下限條款在市價回檔時的負擔——被解讀為週期末端的壓力訊號。
- **雲端巨頭的完美劇本**:模型碎片化(5-10 個模型並立)讓客戶選擇困難,平台調度/管理費因此落袋,AWS 對開源模型最積極。

## 主題一-三|Kimi K3 = DeepSeek 2.0?(核心大主題)

- **Moonshot(月之暗面)Kimi K3:2.8 兆參數 MoE(896 專家/每次啟用 16)、100 萬 token 上下文、原生多模態**;多項評測全球前四,前端代碼領域擊敗 Claude Fable 5 與 GPT-5.6 Sol;**7 月底完全開源權重**
- 實測陷阱:「話癆」—— 預設最大推理模式,輸出 token 約為同儕兩倍 → **帳面價格便宜、實際任務成本 ≈ GPT-5.6 Sol** —— 核心指標應為「每美元買到多少有效智慧」;讀者 Dylan Oh 補充:quantile balancing 專家調度 + 自研 Kimi Delta Attention(混合式,長上下文不用平方級重算)= 晶片限制逼出的工程進化
- 與 DeepSeek 的不同:非價格破壞,是**首款在特定實戰場景與第一梯隊硬碰硬的中國旗艦** —— 「開源不夠強的時代可能結束」;對政府/金融 = 無需依賴美國 API 的頂級選項
- **對閉源雙巨頭**:動搖定價權(「最聰明」輸給「夠用且便宜」的商業現實);Anthropic 以寫程式為賣點,受壓尤明顯。**雲端巨頭暗中樂見模型碎片化**:5-10 個模型並立 → 客戶選擇困難 → 平台調度/管理費落袋(AWS 對開源最積極)—— 「天下大亂,群雄割據」才是 hyperscaler 的完美劇本
- **會令 AI 支出減少嗎?否,三個機制**:①軍備競賽的領跑者壓力(對手逼近 → 領先者只會加速燒)②雲端巨頭以 cloud credits 閉環供血(投資變自家雲營收,現金流壓力低)③**傑文斯悖論:token 價跌 50% → 企業不是省一半,是塞進以前不敢用的場景(多模型路由/Agent 自我糾錯 = 成百上千倍消耗)** → 推理算力需求爆發。價值向上下游轉移:基建 + 編排層/工具鏈;焦點從「哪家模型最強」轉向「系統工程」

## 主題四|微軟:逆向資訊悖論與 Frontier Tuning

- Nadella 引 Arrow 資訊悖論的倒轉:**AI 時代承擔風險的是買方 —— 企業付兩次錢(token 費 + 把內部 know-how 免費送給模型廠商變聰明)**;與 Karp 兩週前的怒罵遙相呼應 = 巨頭聯手立「資料主權」新共識
- **Frontier Tuning**:Azure 邊界內的私有強化學習環境(RLE)—— 隔離沙盒 + 導入企業數據與員工糾錯軌跡 + 學習成果不外流;早期客戶 Land O'Lakes:複雜報告準確度 90%+、**token 效率 ~10 倍**
- 戰略:從低毛利「代幣銷售」升級「系統平台」;**「既賣矛(OpenAI 股東)又賣盾(防模型廠商的防彈衣)」 —— 「模型是流水的兵,Azure 才是鐵打的營盤」**;底層模型是誰不重要 = 削弱所有模型廠商談判籌碼

## 主題五|蘋果起訴 OpenAI:終端入口之爭

- 訴狀細節:OpenAI 以 ~$65 億購 Jony Ive 的 io Products、挖角 400+ 蘋果硬體人員、面試要求展示未公開原型零件
- 本質:OpenAI 從「軟體互補品」越線成「硬體替代品」(後手機時代新終端)→ 蘋果必須在其羽翼未豐時用法律+生態全力阻擊(拉高成本、拖慢時程)
- 老巨頭 vs 新貴:蘋果×Google = 地盤默契(每年數百億美元預設搜尋費 = 相互保證毀滅);OpenAI = 無包袱掀桌者(模型同質化 → 沒有分發通路就是巨頭生態的打工仔)
- **權力結構位移:「模型為王」→「系統層為王」** —— 入口排他性(誰控制裝置誰決定流量分給哪個模型)、端側+私有雲的數據護城河、硬體換機週期的現金流穩定性。全棧(晶片→硬體→OS→通路→用戶)是演算法速成不了的壁壘

## 主題六|CoreWeave 研議「做空」供應商(Reuters 7/14)

- CRWV 與投行研議買入 **美光/SK 海力士個股賣權(Put)** 對沖 LTA 風險:長約的**價格下限條款**在市價回檔時變成負擔(被綁死以高價採購 + 庫存跌價)
- 人設吻合:創辦團隊 = 天然氣對沖基金出身 —— GPU/記憶體 = 大宗商品,算力中心 = 要鎖定輸入成本的加工廠;一貫擅長結構化融資(GPU 抵押貸款/客戶長約信用背書)
- 局限:個股 ≠ 晶片實物價格(避險不精準)、個股選擇權流動性有限(大額成本高)—— **暴露半導體缺乏原油式標準化衍生工具的空白**
- 對記憶體廠的雙面解讀:正面 = 買方認真對待合約(賺了避險就心平氣和履約 = 營收確定性增)/ 負面 = **「大客戶預期晶片大跌」的情緒訊號,週期末端的額外壓力源**
