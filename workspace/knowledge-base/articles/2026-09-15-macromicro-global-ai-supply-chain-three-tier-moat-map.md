# M平方 AI 供應鏈專區上線:用「營收 × 毛利率」把上中游分成三層護城河

## Summary

M平方 2026-09-15 訂閱快報,配合「AI 供應鏈」專區正式上線,重新梳理全球 AI 電子供應鏈上、中游,用**營收與毛利率趨勢**把各環節分成三類:**①護城河最穩**——晶圓代工與記憶體,產業高度集中、技術壟斷、也是當前最大缺料瓶頸,台積電 26Q2 三率創高、Q3 財測 446-458 億美元、全年美元營收上修到「略高於 40%」,記憶體龍頭 25H2 起營收年增創高、**毛利率達 80%**,三大廠首度簽 5 年期長約鎖需求;**②新技術與用量增加**——ABF 載板、CCL、PCB、散熱、光通訊,從配角變「不可或缺」,毛利率逐步攀升,驅動是異質整合讓晶片變大、層數變多、Bump 變多,散熱走向液冷(TrendForce:AI 晶片液冷滲透率今年破五成、2027 近六成),光通訊往 NPO/CPO/Optical I/O、NVIDIA 8 月宣布 CPO 版 Spectrum-X Photonics 量產;**③高度競爭風險大**——組裝 ODM,承接上游漲價、長短料交期錯配、庫存明顯增加,不是需求轉弱而是瓶頸造成短期獲利承壓。晶圓代工的庫存細拆是關鍵訊號:原料與在製品創新高、製成品低檔 = 訂單滿載且交付順利;資本支出仍有紀律、未重演 2022 Overbooking,自由現金流 25H2 起顯著攀升。結論:**短期 AI 晶片層營收增速快於庫存、處正向循環,AI 基礎建設層因 VR200 架構問題庫存被動堆積、待全面量產後疏通;長期科技巨頭與新雲 2026 capex 突破 8,000 億美元、表外融資擴大,RPO 能否取代 capex 讓商業模式落地是核心,所幸 Token 用量爆發、AI Agent 進入企業工作流。**

## Key Takeaways

- **三層分類法(本篇核心工具)**:護城河最穩(晶圓代工/記憶體:營收毛利大幅成長 + 高度集中 + 技術壟斷 + 缺料瓶頸)→ 新技術與用量增加(封測/ABF/CCL/PCB/散熱/光通訊:營收毛利逐步攀升)→ 高度競爭風險大(組裝:營收毛利承壓、門檻低、被轉嫁成本)。用毛利率斜率判斷議價權在哪一層。
- **晶圓代工議價權最強、且有 CapEx 紀律**:台積電 26Q2 三率同創新高;Q3 財測 446-458 億美元(7、8 月已 307 億);2026 全年美元營收「超過 30%」上修至「略高於 40%」。全球半導體銷售額續攀升 = 供給有限缺貨漲價鐵證;資本支出審慎未失控,自由現金流 25H2 顯著攀升——漲價已轉成現金。
- **晶圓代工庫存三拆是健康訊號**:原料創新高(客戶下一代晶片研發、訂單滿載)、在製品創新高(量產中)、**製成品低檔**(交付順利、庫存健康、持續轉營收)。
- **記憶體超級週期 + 首度長約**:產能轉 HBM/DDR5、縮減 EOL DDR4,新舊世代同步供給收斂漲價;龍頭 25H2 營收年增創高、毛利率 80%。三大廠簽約 5 年期(定價/採購量/財務保證),三星「滾動基準」每年談判、達成共識就延一年維持約 5 年——目的是避免再陷景氣循環惡夢。系統效能指標從「算多快」變「能算多少」(Token/$、Token/W),記憶體將垂直堆疊到 xPU/ASIC 上方、向運算核心近移。
- **先進封裝與載板是新戰場**:摩爾定律撞牆 → 異質整合多晶片封裝 → I/O 接點增加 → 載板尺寸擴大、高層數 → ABF 需求大增;為克服大尺寸翹曲與高頻損耗導入玻璃核心。Bump 越多 ABF 層數越多,層數越多熱翹曲良率越低,加上上游 T-glass 產能瓶頸 → ABF 供給緊俏、營收毛利同步攀升。CoWoS 面積擴大、HBM 堆疊增加、FOPLP 發展;台積電下放 CoWoS 的 oS 環節,封測往高附加價值延伸。
- **CCL/PCB 結構性升級**:CCL 因 M7-M9 高頻高速規格 + 上游玻纖布與銅箔極度緊張 → 供不應求高毛利;PCB 主板極高層數 + 高階 HDI + 光模組板導入 mSAP,產值與獲利結構顯著跳升。
- **散熱從零組件到系統再到晶片**:高階 AI 晶片 TDP 普遍破 1kW、整櫃數百 kW,氣冷逼近極限;TrendForce 估液冷滲透率今年破五成、2027 近六成;散熱業轉型全套液冷系統(CDU/Manifold/Rack)供應者,與晶圓廠協同「封裝級散熱」(Cold Plate/均熱片),未來走「矽晶圓級」直接在晶片或基板刻微流通道;26H2 VR200 順利出貨將再推營收。
- **光通訊往 CPO/Optical I/O,瓶頸在熱、翹曲、光耦合、測試**:核心趨勢是光學引擎越靠近 xPU/ASIC,封裝從平面走向 2.5D/3D 讓 EIC 與 PIC 更緊密;高溫翹曲影響光纖與波導對位,測試流程前移到晶圓/晶粒,先進封裝、測試設備、光學量測價值同步升。美系大廠:800G → 1.6T 與 OCS 加速轉型,NPO/CPO 未延期、磷化銦產能瓶頸正被克服,**2030 OCS TAM 翻倍至 40 億美元**;NVIDIA 8 月宣布 CPO 版 Spectrum-X Photonics 量產。
- **ODM 組裝段暫時承壓,長短料是最大風險**:承接晶片/零組件/機櫃成本上升,缺貨交期拉長使伺服器造價攀升、庫存明顯增加;缺料延後整機出貨 + 上游漲價無法即時轉嫁 → 壓毛利。定性:不是需求轉弱,是供應鏈瓶頸造成短期獲利承壓。
- **M平方結論**:短期各產業環環相扣,AI 晶片層營收增速明顯快於庫存(強勁正向循環),AI 基礎建設層因 VR200 架構問題庫存「被動堆積」,待全面量產後看中游庫存壓力緩解;長期 2026 巨頭 + 新雲 capex 突破 8,000 億美元、表外融資擴大,**RPO 能否順利取代 capex 讓商業模式清晰落地是未來重點**;Token 用量爆發、AI Agent 進企業工作流 = 應用正轉成生產力。

## 一、專區介紹與三大獲利分類

- 「AI 供應鏈」專區正式上線,獨家建構上、中、下游追蹤架構,整理各環節重要指標與代表公司(涵蓋清單將定期維護)
- 分類依據 = 營收與毛利率趨勢;上、中游拆成三層(見 Key Takeaways 第一條)

## 二、護城河最穩:晶圓代工與記憶體

### 晶圓代工
- 台積電 26Q2 三率同步創歷史新高,AI 需求向上游傳導、轉化為晶圓代工與先進封裝漲價紅利;先進製程稀缺使其成議價力最強環節之一
- Q3 財測 446-458 億美元(7、8 月已 307 億)再超預期;2026 全年美元營收由「超過 30%」上調至「略高於 40%」
- 營收絕對值與年增率不斷創高;全球半導體銷售額持續攀升
- 資本支出保守紀律、審慎擴產,避免 2022 Overbooking
- 自由現金流 25H2 起顯著攀升——議價權上移 + 投資紀律 → 漲價轉現金
- 庫存三拆:原料新高(研發訂單)/ 在製品新高(量產)/ 製成品低檔(交付順利)

### 記憶體
- 產能轉 HBM、DDR5,縮減 EOL DDR4;新舊世代同步供給收斂與漲價 → 新一輪超級週期
- 25H2 起龍頭營收絕對值與年增率創高,毛利率 80%,與晶圓代工同樣反映議價權上移
- 三大龍頭在報價飆升時首度簽長約(多 5 年期;圍繞定價、採購量、財務保證);三星滾動基準每年談判、達成共識延一年維持約 5 年
- 一、二線產品同步漲價帶動產業結構升級;系統效能決定於「能算多少」(Token/$、Token/W),記憶體架構走向垂直堆疊於 xPU/ASIC 上方、協同設計與封裝、向運算核心近移

## 三、短期爆發最強:量的爆發、良率瓶頸

### 先進封裝與載板
- 突破單晶片微影光罩與良率極限 → 載板全面轉「異質整合與多晶片封裝」→ I/O 接點增加 → 載板尺寸擴大、高層數與封裝化 → ABF 需求大增
- 大尺寸載板翹曲與高頻損耗 → 導入玻璃核心等新材料;載板從承載結構變先進封裝核心技術
- Chiplet 整合使封裝尺寸大增 → Bump 增加 → ABF 層數增加 → 熱翹曲良率下降 + T-glass 與原材料產能瓶頸 → ABF 供給緊俏,營收毛利同步攀升
- 效能提升轉向晶粒堆疊與異質整合,先進封裝從後段製程升級為決定效能/功耗/良率的核心;CoWoS 面積擴大、HBM 堆疊增加、FOPLP 發展
- 台積電部分下放 CoWoS「oS」環節,封測業者往高附加價值延伸;需求強、產能緊 → 毛利率攀升

### CCL / PCB
- CCL:M7-M9 高頻高速規格升級 + 上游玻纖布與銅箔極度緊張 → 供不應求、高毛利
- PCB:主板極高層數與高階 HDI + 光模組板導入 mSAP → 產值與獲利結構顯著跳升

## 四、長期斜率最陡:未來技術突破

### 散熱
- 高階 AI 晶片 TDP 普遍破 1kW,整櫃 AI 伺服器數百 kW;氣冷逼近極限 → 先進液冷成高階 AI 基礎設施標配
- TrendForce:液冷在 AI 晶片滲透率今年破五成、2027 近六成;散熱業平均營收近兩年不斷創高,26H2 VR200 出貨再推升
- 轉型全套液冷系統(CDU/Manifold/Rack)供應者;與晶圓廠協同「封裝級散熱」(Cold Plate/均熱片);未來「矽晶圓級」直接刻微流通道
- 散熱成貫穿「矽晶圓-封裝-機櫃」的垂直核心技術

### 光通訊
- 架構演進:插拔式光模組 → NPO → CPO → 光學 I/O;光學引擎越靠近 xPU/ASIC,縮短電訊號距離、降功耗延遲、升頻寬
- 封裝從平面整合走向 2.5D/3D 異質整合,EIC 與 PIC 更緊密 → 提升傳輸效率與頻寬密度,但拉高設計、封裝、測試門檻
- 瓶頸:熱與翹曲影響光纖/波導對位、訊號損耗與光耦合難度增;EIC+PIC 整合使測試對準難度高於傳統半導體,測試前移至晶圓、晶粒、模組、系統;封裝精度/光學對準/測試要求提高 → 先進封裝、測試設備、光學量測重要性升
- 美系大廠電話會:800G → 1.6T 與 OCS 加速轉型,NPO/CPO 未延期,前端磷化銦產能瓶頸正被克服;2030 OCS TAM 翻倍至 40 億美元
- 光通訊晶片與設備產業營收毛利逐步上升;NVIDIA 8 月宣布 CPO 版 Spectrum-X Photonics 進入量產

## 五、風險最大:組裝 ODM

- AI 硬體漲價逐步傳導至組裝端;ODM 為製造鏈最下游,承接晶片、伺服器零組件與機櫃成本上升;上游缺貨、交期拉長、供應鏈錯配 → 伺服器造價攀升、組裝廠庫存明顯增加
- 短期最大壓力 = 長短料 + 成本轉嫁時差:缺料延後整機出貨造成資金與庫存壓力;上游漲價無法即時轉嫁壓縮毛利
- 定性:並非需求轉弱,是供應鏈瓶頸造成短期獲利承壓

## 六、MM 研究員結論

### 短期
- 各產業環環相扣;AI 晶片層最先量產且供應瓶頸巨大,營收增速明顯快於庫存增速,強勁正向循環
- AI 基礎建設層因先前 VR200 架構問題量產出現短暫瓶頸,庫存「被動堆積」;待 VR200 全面量產後應看到中游庫存壓力緩解、供應鏈疏通;在此之前長短料交期錯配是主要關注風險

### 長期
- 供應鏈產能轉化為生產力才是核心;AI 算力供應層(巨頭 + 新雲)2026 capex 突破 8,000 億美元,表外融資持續擴大
- 大量堆積的 RPO 能否順利取代 capex、讓 AI 商業模式清晰可見並落地變現是未來重點
- 全球 Token 使用量持續爆發、AI Agent 進入企業工作流,AI 應用正式轉換為生產力;應用創造需求,最終成為經濟成長養分
