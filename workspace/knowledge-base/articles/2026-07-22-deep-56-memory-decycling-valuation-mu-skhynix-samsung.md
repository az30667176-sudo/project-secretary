# 記憶體擺脫週期了?單位數 PE 真的是在撿便宜? - 深入分析第 56 期

> 核心結論:「這次既不一樣,也有一樣的地方」—— 記憶體正在去週期化,但只變了一部分。估值要算的是中間平衡點。低 PE 在週期股身上不是價值訊號,是「你正站在山頂、分母即將蒸發」的警訊(2018 年美光 4-5 倍 PE 後 12 個月 −50% 的重演警告)。

## 全文重點結構

**第一章|記憶體為何是週期股**:三基因 —— 大宗商品(規格對了就能換供應商,無定價權)/ 建廠 2-3 年前置期 / 產能開出即洪水。實績:美光 2021 +$58.6 億 → 2022 +$86.9 億 → 2023 **−$58.3 億** → 2025 +$85.4 億;SK 海力士 2023 −9.1 兆韓元 → 2025 +42.9 兆。對照台積電 2023 衰退年仍賺 $263 億(連重傷都算不上)。估值工具:記憶體歷史用 PB(谷底安全邊際),但 PB 量不出 HBM 溢價。

**第二章|台積電如何去週期化(模板)**:四步 —— ①賣客製化生態系非產能(獨吃蘋果、InFO)②極高轉換成本 → 定價權 ③資本紀律(與客戶提前 2-3 年容量規劃)④多平台驅動(HPC 51% > 手機 35%)。結果:PE 12-15x 永久躍升 20-35x;2023 逆勢漲價 = Price Maker 證明;股東結構從對沖基金換成主權基金/長線資金 → 波動下降 → 估值地板抬升。

**第三章|這次不一樣的部分**:①HBM = 半客製化(共同開發、提前 2-3 年送樣、平台綁定、轉換代價高)②需求 = 晶片出貨 × 單顆容量的**相乘**(H100 80GB → B300 288GB = 3.6 倍;UBS 估 2026 +90%、2027 +77%)③AI 拉動整座金字塔(HBM/Server DRAM/eSSD)④**首次「接受預約」:美光 16 份策略協議,2026-2030 約佔 DRAM 出貨 20%、NAND 1/3,含 take-or-pay + 價格上下限 + 客戶存款**⑤TrendForce:HBM 佔產能 2025 18% → 2026 22% → 2027 ~30% → 排擠效應撐住普通記憶體價格。

**第四章|仍然一樣的部分(物理規律)**:①HBM 是硬體不是軟體 —— 2026 年 22% 產能只換 9% 位元(良率損耗+底層晶片佔面積);**今天缺貨的同一特性,明天就是供給追上的引擎**②新廠三道關卡:良率爬坡 2-3 季 + 客戶認證 1-2 季 + 產能爬坡 2-4 季 → 愛達荷 2027 年中首晶圓 → **實質衝擊 2028 上半年**③客戶必養備胎(NVIDIA 不容忍被單一廠綁架);三廠 HBM4E 送樣時程貼身④高售價≠高毛利(2026Q1 普通 DDR5 現貨暴漲時獲利反超合約價鎖定的 HBM)⑤傳統業務仍是純週期(NAND 可靠堆疊層數快速增供)⑥中國 CXMT/YMTC 衝擊低階池(2028-2030 若取 10-15% 份額)⑦**三線交匯於 2027H2-2028:新產能開出 + 排擠鬆動 + 需求增速自然放緩(2026 高點 → 2027 60-80% → 2028 35-55%)**。

**第五章|地板墊高了多少(核心量化)**:拆「結構性獲利 vs 週期性超額獲利」。壓力測試:重演 2019 級下行(DRAM −47%/NAND −30%),四板塊保留率加權 —— HBM(營收 32.5%,保留 80%)+ Server/eSSD(27.5%,55%)+ 傳統 DRAM(22.5%,20%)+ NAND(17.5%,15%)≈ **整體保留 48%**(vs 2019 實際 SK 海力士只剩 15-20%)。三情境:**硬著陸 20% 機率 → 保留 30-40% / 軟著陸 55% 機率(base)→ 50-60% / 長期高原 25% → 70-80%**。

**第六章|儀表板(每季對帳)**:兩條領先線 —— ①庫存搬家(AI 時代修正:Hyperscaler 買回去是裝機部署 = 在建工程,要盯 capex 增速而非通路庫存天數)②**價格斜率(加速度歸零 = 黃燈;Server DDR5 漲幅兩季內從近 100% 驟降到個位數,美光自己說 meaningful moderation)**。**今日讀數:黃燈** —— 綠燈(成品庫存 3-4 週遠低於正常 6-8 週/合約價續漲/新供給未開/四大 capex 7,000 億+/獲利創紀錄)vs 黃燈(斜率收斂/OEM 預防性備貨超實需 10-15%/HBM 封裝瓶頸緩解/消費端疲弱)。「繁榮沒結束,但最好賺的那段已經過去了。」三組讀數:轉彎訊號(兩條亮 = 尾聲:Hyperscaler capex 連兩季降 / 合約價連兩季負增長 / 供給同窗過認證)、護欄驗證(下坡頭兩季才驗得到:HBM 重議跌 <10% or >20% / Server 需求 / 資本紀律)、上修訊號(繁榮期就看得見:推理二次加速 / HBM 重議不跌 / 高品質業務 >70%,第一條冒頭就考慮加碼別等確認)。

**第七章|Reverse DCF(以 7/17 收盤 $849 推算)**:表面 fwd PE 6.8x = 旺季小費幻覺。真高峰大概率在 **FY2027(EPS $145-160 中位 $150、FCF ~$720 億)**,FY2026($124/$680 億)作保守對照。**FCF 鏡頭:$849 隱含保留率 ~80%(高於 base 的 50-60%,樂觀)**;各保留率對應:35% → $450 / 50% → $585 / 55% → $630 / 60% → $675 / 80% → $855。**EPS 鏡頭:12-16x 常態 PE 反推,$849 只隱含保留 35-47%(低於 base,偏保守)**。矛盾的解:建廠期 FCF 被 capex 壓低是假象,市場定價「先種樹(2026-27)→ 過渡(2028-29 capex 降、FCF 逆勢衝高)→ 收成(2030+)」。**結論:$849 = 「軟著陸如期發生」的價格,合理但無太多餘裕;硬著陸情境 $450 = 約 −50% 下行**。前提:FY2027 高峰要真的出現(DRAM 上半年續正增長 + HBM4E 準時 + AI 出貨 30%+ + 無宏觀斷崖),任一不成立則高峰停在 $124-130、安全邊際立刻變薄。

**第八章|三家同錨 + 錨與繩**:三家同一產業 beta,差異互相抵消 —— SK 海力士(品質最高但韓國折價+單一客戶)/ 美光(透明+長約但已充分反映+美國建廠成本高 50-100%)/ 三星(集團折價+良率疑慮但期待極低+下游對沖)。估值是錨不是目的地;五股力量拉離錨(敘事動能/被動資金流/籌碼/時間維度錯配/反身性)。估值的三個實用問題:現價買入需要相信什麼 / 錯了下行多少(849 → 450 = −50%,決定部位大小非決定買賣)/ 什麼價格賠率轉有利(恐慌殺到 <500 = 用硬著陸價格買軟著陸資產)。**「週期的輕鬆錢賺完了,結構的硬仗才剛開始」** —— 下一階段賭的是 HBM 年度重議守價、新廠回報、組合升級、資本紀律。附帶一張免費看漲選擇權:若 AI 需求指數型脫韁(Agent/邊緣 AI/AIGC),保留率 70-85%、現價回頭看反而保守。

## 讀者補充(KunHan Lee 留言,獲 KP 回覆)

NAND 這輪暴漲主因已非「HBM 排擠 → 溢出」,而是 **AI inference 的結構性換位:Decode 階段極度依賴 KV cache,HBM 放不下、NAND 是最經濟解** → NAND 從儲存旁觀者變推理架構核心,Agentic AI 再乘一個量級。兩個硬證據:①NVIDIA CES 2026 發表 ICMS 架構(GTC 改名 CMX,BlueField-4,2026H2 出貨)—— **把 NAND SSD 制度化為 HBM 與網路儲存之間的固定「context 記憶體層」**;②DeepSeek V4(2026/4)靠壓縮+分層 offload 讓 KV cache 大規模落到 SSD 經濟上成立,三個月內 Anthropic/OpenAI/Kimi K3 全跟進。這解釋了 SNDK 何以是 S&P500 年度漲幅冠軍、Kioxia 市值一度登頂全日本。
