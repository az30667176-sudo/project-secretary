# 週58:Nvidia×聯發科 ASIC 佈局 / OpenAI 斷供 Cursor / 非農 16.2 萬 / AVGO 毛利率之謎 / 日圓保衛戰

> KP 開場自白:FOMO 研究院不是純 AI 專頁,第一篇是 Novo Nordisk GLP-1;引 Munger「只有錘子的人看什麼都是釘子」—— 跨學科不是分心而是望遠鏡。本期五主題,每一個都能單獨成篇。

## 一、Nvidia 35 億投聯發科 —— 買的不是股權是「機架控制權」⭐

**表面**:NVDA 投 MTK $3.5B。**本質**:客戶自研 ASIC 擋不住,那就讓每一顆 ASIC 都透過 NVDA 介面連進 NVDA 機架。

### NVLink Fusion 三層外殼
1. **晶片溝通**:客戶 ASIC ↔ NVDA CPU 高速低延遲
2. **高速網路**:機架內幾十顆晶片互聯,客戶裝 NVDA 專用橋接晶片直接接進 NVDA 網路
3. **記憶體控制**:把 HBM 控制器移到 NVDA 基礎架構 → 客戶 ASIC 省 ~25% 空間拿去算力

**目標**:客戶「自研」實際上只自研算力核心,記憶體/互聯/網路/機架/散熱/電力/軟體全部 NVDA。

### 為何是 MTK
- 新一代 AI 超級伺服器單櫃用電/發熱 = 傳統 10 倍,必須全液冷 + 重做電力結構
- 除 Google/AMZN 有千人團隊能自己解,其他中小雲/AI 實驗室搞不定周邊配套
- 有 Fusion 認證後,MTK 從「賣零件工程師」升級成「一整套系統統包商」
- **客戶三大好處**:①省敲門時間(NVDA 背書勝過 200 業務)②CoWoS 產能特快車(NVDA 家人優先)③台積電眼中定位轉變 —— 從搶產能第三者變幫 NVDA 帶客的自己人

### MTK 三條業務線
1. 手機/電視晶片(主要獲利)
2. 傳統客製化(Sony/MSFT 遊戲機、電信網路設備)
3. **AI 資料中心 ASIC**(NVDA 此次目標,全新高利潤線)
- 十年前想挑戰 Broadcom 做自有品牌交換器,失敗後改當「頂級承包商不搞自有帝國」的心態 —— **恰好是 NVDA 要的** (vs AVGO 想建完整生態一手包)

### 金融工具 —— 五年零息海外可轉債
- 對 MTK:超便宜美元融資付台積電 wafer + HBM
- 對 NVDA:「信用保證 + 期權看漲」—— 失敗拿回本金、成功分享股價 → 趁 MTK AI 早期把 NVDA 標準深整合進底層,比未來談判划算

### vs Marvell $2B 投資 —— 拼圖不同
- **MRVL 解「跨晶片通訊」**:剛收 Celestial AI 拿到頂級矽光子;NVDA 買的是「用光代替電」讓客戶 ASIC 出了晶片後光速接進 NVDA 機架
- **MTK 解「實體整合與落地」**:與 TSMC 深合作 + 高速 I/O + 省電;NVDA 買的是「頂級實體建造工藝」
- **一句話**:MRVL 讓晶片能溝通,MTK 讓晶片能安裝運行

### 真正目標 —— 孤立 AVGO
- NVDA 夥伴名單有 Intel/MRVL/MTK,**沒有 Broadcom**
- 因為 AVGO 正打造完全繞過 NVDA 的替代方案:超乙太網聯盟 + 高階交換晶片 + 完整 ASIC 到光模組藍圖 —— 科技巨頭找 AVGO 就能建「去 NVDA 化」AI DC
- **NVDA 策略明確**:支持第二名 (MRVL)、扶持第三名 (MTK)、孤立第一名 (AVGO)
- 現況:AVGO 仍是主承包商,Google 合約到 2031、2027 仍能看到千億級 AI 營收;但客製化市場正從一家獨大走向「客戶要第二選擇」階段
- 黃仁勳潛台詞:**「你可以不買我旗艦 GPU,但你絕對無法在不用我系統架構/網路/互聯標準的情況下建 AI 集群。」**

## 二、OpenAI 斷供 Cursor —— 應用層護城河只是幻象 ⭐

### 事件時序
- Cursor 2 年做到年營收 $4B、估值 $500億,靠「工作流程整合」不是自研模型
- 2026/8 SpaceX 以 $60B 全股票收 Cursor(xAI 是 SpaceX 子公司 → Cursor 一夜變 Grok 直營專賣店)
- OpenAI 隨即宣布斷供,啟用「控制權變更條款」(該條款一般少用因為要放棄客戶收入)

### 5% vs 10 億 —— 兩個數字如何同時成立
- Cursor CEO:OpenAI 只佔總流量 5%
- OpenAI 內部估:此合作年營收 >$1B,Cursor 曾是前五大客戶
- **兩者都對**:Cursor 兩層計費,95% 簡單活自家或便宜模型;5% 高階系統/大資料才調 GPT 頂級模型 —— 次數少但每次貴,而**企業訂閱看重的就是這 5%**
- 斷供代價:OpenAI 放棄 $10B/年;Cursor 失去產品最關鍵賣點

### 為何現在斷?—— 新一代 Astra 即將發布
- 「一個正打你官司的對手買下你最大經銷商」—— 提供技術等於送核心到對手陣營
- 給一般客戶合理商業風險;給資源充足直接競爭對手 = 不能忍

### Anthropic 雙標 —— 這次選留下
- 一年前 OpenAI 傳收購 Windsurf → Anthropic 幾天內就斷 Windsurf
- 今年初也因競爭對手工程師透過 Cursor 用 Claude 而暫停過
- **這次留下的關鍵 = SpaceX 的三重身份**:
    1. Anthropic 房東(5 月起租 SpaceX 全部運算設備,月租 **$1.25B**)
    2. Grok 母公司(競爭對手)
    3. Cursor 母公司
- Anthropic 斷 Cursor = 得罪自己設備供應商 + Claude 是 Cursor 用戶最愛丟大量收入 + 可能影響 $1.25B/月合約
- **不是夥伴信任是每月 12.5 億美元的利益牽制**

### 三方策略取捨
- **OpenAI**:丟批發量換確定安全邊界;把開發者逼回 ChatGPT/Codex 一等公民通道
- **SpaceX (Cursor)**:失去中立招牌,抓牢工程師使用習慣 + 每日真實程式碼數據;Grok 未強時先靠出租算力賺租,強了接管軟體全收
- **Anthropic**:賺眼前銷售,產品擺在對手店裡賣,數據會不會被拿去訓練是未知

### KP 結論 —— 應用層垂直整合才是護城河
**「包一層別人模型再賣」的應用層護城河只是一種商業幻象**。

## 三、非農 16.2 萬 —— 為何升息機率只從 50% → 60%

### 16.2 萬的含金量拆解
| 項目 | 貢獻 | 說明 |
|---|---|---|
| 餐飲服務 | +5.9 萬(過去年均 1.2 萬) | 反彈 |
| 地方政府教育 | +4.2 萬 | 暑假結束季節性回補 |
| **合計** | **10.1 萬 = 62%** | 集中在兩行業 |
| 醫療保健 | +1.3 萬(過去年均 3.2 萬) | 弱 |
| 資訊業 | **-2.3 萬** | 數據處理/出版/廣播 = **AI 取代白領最直接體現** |
- 薪資年增率 3.2% → **3.1% 微降** = 沒有「薪資-通膨螺旋」跡象

### 為何機率只升 10%
- 非農前 Fed 理事 Waller(9/3):「有條件按兵不動 → 給通脹降溫機會」,但 **「通脹火熱就會考慮」**
- NY Fed 主席 Williams(9/2):等完整數據(下週 CPI),沒否決 9 月升息,決定權交給通脹軌跡
- **關鍵基調**:勞動力市場不是決定變量,**通脹才是**

### 數據噪音提醒
- 兩天前 ADP 顯示疲軟 + 前兩月上修 5.5 萬 → 短時氛圍徹底翻轉
- 暑期季調充滿統計雜訊,點狀預測在誤差範圍面前脆弱
- **標題數字 vs 預期落差不必執著,要看產業變化 + 薪資走勢**

## 四、AVGO CEO Hock Tan:別看毛利率,看營業利潤率

### 事實
- Q3 營收大漲,毛利率 77.1% → **75%**,Q4 指引 **73%**
- 但 Q3 半導體營收 +127%,營運費用只 +22% → **營業利潤率 67.9% 歷史新高**,Q4 指引 66%

### Hock Tan 為何正確
- XPU 模式:買 HBM 進來封裝進晶片整包賣客戶 → 記帳更像「代購加組裝」,維持過去 80% 毛利不切實際
- HBM 採購成本(影響毛利率)= 市場決定 CEO 控不住
- 開銷/人力(影響營業利潤率)= CEO 說了算,做得漂亮 → 他叫你看他掌控力最強的成果

### 但毛利率仍重要 —— 結構性訊號
- 以前:輕資產晶片設計 + VMware 軟體(毛利 94%)
- 現在:XPU 佔營收 Q2 49% → Q3 56% → **Q4 指引 62%**;高利潤軟體被稀釋
- 這**不同於 NVDA**(NVDA 毛利率降是 HBM 短期漲價的可控週期);AVGO 是**結構性**:只要 ASIC 賣得比軟體快,毛利率繼續掉
- 商業模式從「輕資產設計+軟體」→「扛沉重物料成本的硬體整合」

### 兩個指標的意義
- **營業利潤率**(66%):執行力 / 規模效應 / 控本
- **毛利率下降**:護城河形態 + 資本密度正在改變的**領先指標**
- 兩個對照看才能明白 AVGO 為拿 AI 門票經歷的**基因重組**

## 五、日圓保衛戰 —— 為何撒錢救不了

### 8 月大失敗
- 美日聯手花 **15.4 兆日圓**(單月歷史紀錄)干預匯市,日圓仍慢慢滑回 160 邊緣
- 根因:美日利差太大 —— 全世界資金要把日圓換美元存高息,幾千億美元護盤擋不住蜂擁而至的套利

### G20 週末轉折
- 美國財長 Bessent 見 BOJ 植田 + 財相片山皐月後說:**「我掌握了市場不知道的資訊,我相信日本會做出讓日圓走強的決定。」**
- 植田補:「未來每次會議都可能調整利率。」→ 日圓跳升到 155
- **本質差別**:下場買日圓是治標;讓市場相信利差會縮、財政會收 = 治本

### 日本內閣的雙重矛盾 ⚠️
- 首相高市早苗:**143 兆日圓預算 + 食品消費稅 8% → 1%**
- 央行想升息(踩煞車)vs 財政部大撒幣發債(踩油門)
- 一旦日本財政失控/國債賣不掉 → **可能被迫賣美債救急 → 直接拖垮美國債券市場**
- 美方 G20 態度明確:必須回到可持續財政軌道,不能無限發債

### 美國底線 —— 兩層
1. **官方管道(可控)**:BOJ 干預需要美元可透過 **FIMA 窗口**用美債抵押借,避免拋售
2. **民間金主(難控)**:壽險 + 商銀 + GPIF 持有龐大美債/美股;日圓突然暴漲 + 日本利率快速上升 → 撤資潮 → 拋售美債

### 美國要的是「慢速升息」
- **下限**:日圓不能再破 164(破了又要動用 VIP 通道)
- **上限**:日圓絕不能「暴風式大升」—— 2024/8 BOJ 突升息 → 日股單日 -12% + 美股遭殃,無序暴跌是美國最怕的
- 華盛頓要「可預測慢動作」:每次 0.25%、態度稍鷹派 → 利差慢慢縮,不給市場驚喜

### 日本無痛選項不存在
- 每年 **180 兆日圓國債到期**要借新還舊 —— 比多數已開發國家 GDP 還大
- 利率 1% → 2% = 每年多付 **>20 兆日圓利息**
- 減稅福利(5 兆缺口)vs 飆升利息(十幾兆)在同一張預算表衝突
- **結論**:美方逼出的政策承諾能維持多久,日圓升勢就能延續多久;每次政局動盪/民調下滑,大撒幣衝動就會回來

## 我讀完的四個 takeaway

1. **NVDA-MTK 投資是「機架控制權戰爭」不是背書 MTK AI 能力** —— 這是判斷 MTK 股價驅動因子的正確視角:短期靠 Fusion 認證帶客,長期看 AI DC 業務線能不能真的接到 GOOG/META/OpenAI 訂單。AVGO 才是被孤立的那個。
2. **OpenAI 斷 Cursor + Anthropic 為 $1.25B/月租金而留下** = 應用層護城河是幻象,**巨頭底下租關係鎖死所有動作**。任何 SaaS 只要底下接的是外部模型、又賣給對手/被對手買 → 隨時被斷。要看穩定性先看基座關係。
3. **非農 16.2 萬看似火但質量差**(餐飲 + 教育季節性佔 62%,資訊業 -2.3 萬 AI 取代白領最直接證據)—— 主戰場是 CPI 不是 NFP;Fed 兩位官員明白提示「決定權交給通脹」。
4. **AVGO 毛利率結構性下滑是必要之惡**:XPU 從 49→56→62% 是拿 AI 入場券的代價,不看毛利率會漏訊、只看毛利率會誤判 —— 兩個指標對照才是完整故事;和 NVDA 的可控週期性下滑本質不同。
5. **日圓保衛戰真正是「日本財政 vs 美國施壓」的博弈**,不是匯率技術戰。看漲日圓 = 賭高市內閣能扛住減稅撒幣的政治誘惑;她扛不住的話,日圓再回頭掉。180 兆日圓國債到期 + 利率每漲 1% 就 +20 兆利息 = 沒有無痛選項。
