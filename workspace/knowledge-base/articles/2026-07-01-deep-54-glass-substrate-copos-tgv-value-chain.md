# 玻璃基板全景地圖 - 深入分析第 54 期

## Summary

FOMO研究院 KP 深度分析第 54 期(2026-07-01)拆解玻璃基板全景地圖,核心框架是把「形狀(CoPoS 方形面板)/層級(玻璃中介層 vs 載板核心)/材料(玻璃 vs 有機)」三個常被混為一談的問題分開,並主張**投資不要賭陣營、要找「賣鏟人」,關鍵在量產時程(2026 驗證年 → 2028 前後放量)**。玻璃三大優勢(剛性、可調 CTE、低介電損耗)解決 AI 晶片載板翹曲與中介層晶圓浪費的雙重瓶頸,**台積電/Intel/三星系三路並進**,但裸玻璃僅佔成品成本 10-15%、真正卡關在後段的 TGV 打孔(LPKF 雷射改質標竿)與填銅(量產閘門為 CpK ≥ 1.33,截至刊出無廠商公開達成)。設備端 **Onto Innovation(ONTO)靠 Firefly G3 穿透式檢測拿下玻璃製程控制唯一完整方案**,MKS(Atotech 化學)與 Lam Research(ECD 設備)是填銅環節的核心贏家;康寧(GLW)雖是四大玻璃供應商之一,但作者提醒其股價引擎其實是光通訊而非玻璃基板。文末以風險報酬圖收尾:設備股確定性高但純度低、TGV 純玩家(如台灣鈦昇)純度最高但時程風險最大,**ONTO 是確定性與純度的相對舒服平衡點**。

## Key Takeaways

- **三軸拆解框架**:形狀(CoPoS)/層級(玻璃中介層 vs 玻璃核心載板 GCS)/材料(玻璃三王牌:剛性、可調 CTE、低介電損耗)是三個獨立問題,不能混為一談。
- **三巨頭三路線**:台積電穩健(先面板化再驗證)、Intel 超車(投入最早、2030 專利授權路線圖)、韓系速度(Absolics 搶全球首條量產線)。
- **上游材料非標的**:裸玻璃僅佔成品成本 10-15%,四巨頭(康寧/AGC/NEG/SCHOTT)互相制衡無獨佔溢價;**康寧(GLW)股價引擎其實是光通訊,不是玻璃基板**。
- **填銅是真正卡關處**:量產閘門為面板級玻璃金屬化 CpK ≥ 1.33,截至刊出無廠商公開達成;**MKS(Atotech 化學)+ Lam Research(ECD 設備)**是核心贏家。
- **檢測贏家**:Onto Innovation(ONTO)的 Firefly G3 穿透式檢測 + TGV 立體量測,是目前唯一完整的玻璃面板製程控制方案,壓過 KLA。
- **量產時程**:台積電魏哲家表示量產還需兩到三年,業界共識規模量產落在 2028 年底至 2029 年。
- **投資策略**:別畫陣營表,找「賣鏟人」(不管誰贏都收錢);**ONTO 是確定性與純度的相對舒服平衡點**,TGV 純玩家風險報酬曲線最陡。

## 全文重點結構

**第一章|地基危機**:AI 晶片撞上光罩極限(~858mm²)→ CoWoS 拼接;但地基兩層同時出問題 —— 中介層被圓晶圓幾何浪費卡住、有機載板被熱膨脹失配卡住(翹曲)。玻璃同時開兩張藥方。

**第二章|三軸拆解**:①形狀 = CoPoS(方形面板,RDL 利用率大增)—— 與材料無關;②層級 = 玻璃中介層(難,與成熟矽中介層競爭)vs **玻璃核心載板 GCS(較快,Intel 領頭,可由基板廠獨立做、不佔 CoWoS 產能)**;③材料 = 玻璃三王牌:剛性(大面積不翹)/ 可調 CTE(配方調到貼近矽)/ 低介電損耗(高頻省電)。

**第三章|三巨頭三路線**:台積電穩健(先面板化再驗證玻璃)/ Intel 超車(投入最早、宣傳最大,換道超車籌碼)/ 韓系速度(Absolics 搶全球首條量產線、三星垂直整合)。

**第四章|上游材料 = 風向球非標的**:裸玻璃只佔成品成本 **10-15%**,八成五價值在後段微加工;四巨頭(康寧/AGC/NEG/SCHOTT)互相制衡無獨佔溢價。**⚠️ 康寧(GLW)警告:其股價引擎是光通訊部門(AI 資料中心光纖,與 NVIDIA 合作、Meta 數十億美元長約),玻璃基板只是遠期選擇權 —— 「看好玻璃買康寧 = 買錯了故事」**。材料端大量出貨 = 產業鏈進入量產的最早訊號(儀表用)。

**第五章|TGV = 最窄最深的門**:玻璃絕緣必須打孔填銅才通電。三難:脆(熱裂)/ 孔太細深(直徑頭髮幾分之一、深寬比 10-20:1)/ 藥水亂融(碗不是井)。主流解 = **LIDE(雷射改質 + 選擇性蝕刻)**:雷射畫線讓玻璃「極度怕酸」→ 藥水沿線直下蝕出垂直深孔。格局:**德國 LPKF(雷射改質標竿+專利+生態系)+ SCHMID(蝕刻)**;台灣**鈦昇**為最受關注挑戰者(與 Intel 合作多年、進入其開發供應鏈,但成熟度/專利/驗證廣度仍距 LPKF 明顯)。投資註記:TGV 純度最高但業績與量產時程高度綁定、多在海外/台灣掛牌追蹤難 —— 當產業成熟度指標優於當標的。

**第六章|填銅 = 真正卡關處(本篇最重要的一格)**:LPKF 自己都說量產時間由下游「填孔」決定。三物理衝突:銅黏不住玻璃(需奈米附著層均勻覆蓋高深寬比孔壁)/ 填快留空洞填慢貴 / 銅玻 CTE 差撐裂孔壁。**量產閘門 = 面板級玻璃金屬化在商用規格下 CpK ≥ 1.33(AGC 於 IEEE 2025 定義)—— 截至刊出無任何廠商公開達成**。玩家:**MKS(Atotech)化學讓銅「黏得住」+ Lam Research ECD 設備讓銅「填得滿」**;台灣辛耘(濕製程)、弘塑(清洗,CoWoS 已驗證)做落地整合。良率脈絡:65% → ~82%,因初期專攻頂級 AI 晶片、高 ASP 稀釋良率損失 → 不必等 95% 即具商業可行性。**「打孔的進展代表可行,填孔的良率才代表可以量產」—— 有人宣布 CpK 1.33 那天才是下游起跑訊號。**

**第七章|檢測與聯盟**:玻璃透明 → 傳統反射式檢測看到鬼影;薄脆 → 搬運易碎。**Onto Innovation(ONTO)領先:Firefly G3(Clearfind 光學,穿透檢測 + TGV 立體量測數萬孔)+ JetStep X500 曝光機 = 目前唯一完整玻璃面板製程控制方案**;在玻璃賽道壓過 KLA。兩大聯盟:**PACE(Onto 主導龍頭結盟:康寧/LPKF/Lam/MKS/ASMPT,Firefly 已裝進 LPKF 德國 Vitrion 中心)** vs **E-Core System(鈦昇串聯台廠群聚:亞智/群翊/長廣/辛耘等十餘家,一站式+速度彈性)**。

**第八章|終端組裝 = 面板廠×載板廠同桌**:三明治結構 —— 玻璃核心(面板廠主場:舊 3.5/4.5 代線+玻璃搬運/黃光/蝕刻本能,加一台 TGV 雷射機就能拼試產線)+ 上下 ABF 增層細線路(載板廠地盤,玻璃化後仍需要)。群創積極(FOPLP 月產 4,000 萬顆+,往 CoPoS/TGV 走)、友達保守;載板廠(Ibiden/欣興/南電/景碩)雙軌:短期高階 ABF 因 AI 需求吃緊反而有定價權,長期低調布局(欣興 2026 驗證、2027-28 量產)。**2026/6 台積電首度揭露與 Ibiden + 群創三方驗證 CoPoS 玻璃基板**:模擬數據 —— 翹曲 −16%、CTE −19%、彈性模數 +31%、電阻 −27%、電感 −42%;樣品 0.8mm 玻璃核心、5x reticle、85×110mm 無嚴重翹曲分層。**魏哲家:量產還需兩到三年**;三星電機試產線已建、目標 2027;業界共識規模量產 2028 年底-2029。

**第九章|買方與標準戰**:Intel「搶先插旗」(數百項專利 + 開放授權 = 當定規矩收租的人,2030 路線圖)vs 韓系「蓋廠搶快」(先量產成為事實標準)。Absolics(SKC 子公司,喬治亞州全球首座商業玻璃基板廠,中立代工):已向 AMD 送樣,但初期採購量可能不大、**AWS 延後品質測試** = 拓荒者陣痛;**AMAT 持有 Absolics 近兩成股權 = 低成本看漲選擇權(一邊賣設備一邊持股)**。陣營是流動的(LPKF 同時供三星電機+入英美聯盟;康寧兩邊做;AMD 兩邊押;三星電機做載板、三星電子評估中介層)—— **別畫陣營表,找不管誰贏都收錢的賣鏟人**。發令槍 = 買方認證(盯:台積電三方可靠度測試 / AMD 認證後實際拉貨 / AWS 重啟測試 / 巨頭產品藍圖明確列入玻璃)。

**第十章|風險報酬圖**:設備股 = 確定性高但巨頭純度低;TGV 純玩家 = 純度極致、時程風險極大;**ONTO = 確定性與純度的相對舒服平衡**;面板廠 = 轉機性最大、極度考驗耐性(股價爆發性高但要等驗證→營收)。**時間軸:2026 驗證年(送樣/試產/認證新聞轟炸)→ 2028 前後真正放量** —— 買純度高的,等待期心臟要大。

## 讀者補充(CK Chuang 留言,KP 回覆)

CpK 定義精確化:先定義規格公差再看實際輸出的集中度與偏移度 —— 提高 CpK 有兩條路:做得好又穩,**或放寬規格**(留意廠商用後者灌水)。
