# KP 週記 50:Kyber 羅生門 / SKHY ADR / 記憶體擴產 / Meta 反擊

## Summary

FOMO研究院 KP 週記第 50 期(2026-07-10)以「高離散度、個股日振 ±10% 但 VIX 僅 16」的觀察開場,定調當前是「籌碼的期中考」而非系統性危機。SemiAnalysis 報導 NVIDIA **Kyber NVL144 機櫃因 78 層中介板量產難度延後 12 個月以上至 2028**,但 KP 拆解晶片(Rubin Ultra)與機櫃架構(Kyber)是兩件事,若成真將使高階 PCB/CCL 收入後移、成熟 NVL72 週期延長。**SK 海力士 ADR(SKHY)史上最大規模發行 ~$265 億,首日 +12.8%,對首爾原股溢價瞬間衝上 ~15%**,單向閥機制(可贖回不可存入)造成結構性溢價,公司可能藉此發新股收割溢價融資。記憶體擴產進入「賣鏟人」確定性階段:SK 海力士傳 **$80 億 ASML EUV 訂單**,美光 2035 前美國投資上調至 **$2,500 億+**,SEMI 預測 2026-27 記憶體前段設備合計將達 **$1,090 億**。Meta 則以需求(算力全滿載、外租價高得驚人)、供給(加拿大自建燃氣電廠)、成本(Broadcom 協助開發的 Iris/MTIA 新世代)、變現(首度推出付費 API)四件套全面反擊「算力過剩」敘事。

## Key Takeaways

- **Kyber 延期羅生門**:NVIDIA Kyber NVL144 機櫃因 78 層中介板量產難度延至 2028,但 Rubin Ultra 晶片本身仍可用 NVL72 配置出貨,晶片與機櫃架構是兩件事。
- **SKHY ADR 溢價**:史上最大 ADR 發行 ~$265 億,首日 +12.8%,對首爾原股溢價瞬間到 ~15%,單向閥機制(可贖回不可存入)造成結構性溢價,買 ADR 等於付「便利稅」。
- **記憶體擴產賣鏟人確定性**:SK 海力士傳 $80 億 ASML EUV 訂單,美光 2035 前美國投資上調至 $2,500 億+(FY26 capex ~$270 億),SEMI 估 2026-27 記憶體前段設備合計 $1,090 億。
- **HBM 耗晶圓密度**:HBM3E 每 bit 耗晶圓約傳統 DRAM 三倍,層數越高(8→12→16)設備可收費的製程節點越多。
- **Meta 敘事反擊四件套**:需求(算力滿載、外租價驚人)、供給(加拿大自建燃氣電廠)、成本(Broadcom 協助的 Iris/MTIA)、變現(Muse Spark + 首次付費 API,輸入$1.25/輸出$4.25每百萬token)。
- **投資邏輯**:「誰承擔價格不確定性,誰先拿到資本支出確定性」——記憶體大廠賭2-3年後HBM價格,設備商收入發生在答案揭曉之前。

## 主題一|NVIDIA Kyber NVL144 延期羅生門

- SemiAnalysis:Kyber 機櫃(Rubin Ultra 配套,144 GPU 同一 NVLink domain)因**一平方米 / 78 層中介板(midplane)**量產難度,延 12 個月+至 2028;NVIDIA 回「路線圖完好無損」
- KP 拆解:**兩邊講的不是同一件事** —— 晶片(Rubin Ultra)vs 機櫃架構(Kyber);Rubin Ultra 仍有 NVL72(Oberon)等配置可出貨 → 「路線圖沒變」與「Kyber 延了」可同時為真
- 佐證:**Jefferies 6/22 已先示警** —— 若延期,2027 AI PCB/CCL 市場 −5%/−8%;延到 2028 則 −11%/−16%。可信度高於一般傳聞、但未板上釘釘
- 若成真的三層影響:①客戶部署成本升(兩座 NVL72 ≠ 一座 NVL144)②NVIDIA 系統級領先短暫縮小(AMD/TPU/Trainium 窗口略開)③**PCB 價值分配改變:總需求不消失,高階中介板收入後移、成熟 NVL72/銅纜/連接器週期延長 → ASP 與毛利率低於預期**
- 實戰觀測:台灣 PCB/CCL 月營收(高階佔比而非總額)、資本支出、法說量產用詞、券商是否把 Kyber 收入從 2027 移 2028

## 主題二|SKHY ADR:溢價的解剖

- 史上最大 ADR 發行 ~$265 億;首日(7/10)+12.8% 收 ~$168,**對首爾普通股溢價瞬間到 ~15%(一天走完台積電的溢價區間)**
- 機制 = **單向閥**:ADR 可註銷換回原股(出口開),但原股打包成 ADR 受限(入口鎖)→ 套利失效 → 結構性溢價。本質 = 亞洲市場的外匯減震器 + 定價主錨保衛(台積電 ADR 同款,近年溢價數度 >20%)
- UBS 上市前套利指南:買 ADR 空首爾原股 —— 可能是當週韓股疲弱的原因
- **公司是最大受益者**:崔泰源表態開放再發行 —— 用 15% 溢價發新股 = 有利融資窗口(投入 HBM/EUV/新廠)
- ⚠️ 投資人注意:買 SKHY = 付「便利稅」;溢價非常數 —— 監管開放 re-deposit 或流動性危機時可瞬間縮水甚至折價

## 主題三|記憶體擴產的「賣鏟人」確定性

- 兩週內三個歷史級動作:①SK 海力士募 $265 億(超額認購 7 倍)建韓國廠 + 傳 **$80 億 ASML EUV 訂單**(單一採購 = 募資三成)②**美光:2035 前美國投資上調至 $2,500 億+;FY26 capex ~$270 億、FY27 每季 >$100 億 → 兩年合計 >$670 億**;NY Clay 廠首批混凝土提前逾一季 ③韓國政府:三星+SK 西南部 ~896 兆韓元聚落(四座晶圓廠)
- **SEMI 預測:300mm 記憶體前段設備 2026 $520 億(+29%)、2027 $570 億 = 兩年 ~$1,090 億**;DRAM 設備 2026 $370 億;2029 逼近 $800 億
- 關鍵密度事實:**HBM3E 每 bit 耗晶圓 ≈ 傳統 DRAM 三倍**(TSV/堆疊/測試封裝)→ 層數越高(8→12→16),設備可收費的製程節點越多
- **AMAT CEO Dickerson 7/9:客戶已給兩年+設備需求預測,部分到 2030「方向性」展望** —— 歷史級能見度(過去按季看景氣下單)
- 投資邏輯:「**誰承擔價格的不確定性,誰先拿到資本支出的確定性**」—— 三大廠賭 2-3 年後 HBM 價格,設備商的收入發生在答案揭曉之前

## 主題四|Meta 敘事反擊四件套(7/8-7/9)

- ①**需求**:Zuckerberg Bloomberg 專訪 —— 「AI 產業裡沒遇過任何人覺得算力夠用」、Meta 算力全滿載、外部租價「高得驚人」→ 把「蓋太多」改寫成「內用 vs 外租哪個回報高」;②**供給**:加拿大亞伯達 1GW(可擴 1.8GW)資料中心 $91 億 + **自建 932MW 天然氣發電(2030H2)**;算力 2026 7GW → 2027 14GW;③**成本**:Iris(MTIA 新世代,**Broadcom 協助開發**、台積電製造、9 月投產)—— 已部署數十萬顆 MTIA、計畫兩年四代、更新週期壓到六個月;④**變現**:Zuckerberg 消失三年後重返 X 發佈 **Muse Spark 1.1 + Meta Model API(輸入 $1.25/輸出 $4.25 每百萬 token)= 首次閉源付費入口**;Watermelon 下一代訓練中
- SemiAnalysis 同步背書:Meta 是唯一在數據/人才/算力三項都可能世界級的 hyperscaler,今年可能成為算力最多的實驗室
- KP 定調:Meta 在**降低過剩的代價**(廣告/推薦/API/外租四個出口)—— 敘事重立,接下來全看執行(Muse Spark 能否追近 Claude/GPT、API 生態、千億投資變營收)
