# KP 週記 53:去槓桿定調 + 微軟×2 / Meta / 亞馬遜財報拆解

> **開場宏觀(重要風向標)**:七月 AI 殺跌 = **兩成基本面、八成技術面(槓桿多殺多)**;Situational Awareness $250 億基金爆倉 = 「一大批槓桿已被迫出清」的訊號 → 傾向已到**階段性低點**。但**不會快速 V 型反彈**,兩個理由:①**邊際買家換人**(FOMO 滿槓桿散戶 → 懷疑、要求真實盈利、以月/年為單位的資金)→ 板塊內部重排序:**純概念股不會與有盈利股同步反彈**;②**敘事真空**(「只漲不跌」已破滅,新爆發性故事未現 —— 可能是 AI Agent 真正產生收入)。去槓桿後市場回到「能不能賺錢/護城河在哪/三年後還在不在」= 基本面派主場。「沉悶是長期回報最好的朋友」。

## 主題一|微軟:最重要的不是 Azure 43%,是 Copilot 這條曲線

- **付費席位 15M → 20M → 30M+(三個季度,淨增速度季季翻倍)** —— Azure/雲營收/RPO 都是混入傳統搬遷的大雜燴,**Copilot 是唯一純 AI 變現硬指標**
- 消滅 Shelfware 恐懼:滿意度三季翻倍、每用戶對話次數年增近一倍、**每週活躍度已追平 Outlook/Teams**(玩具 → 工作習慣)
- **Attach rate ~6%**(3,000 萬 / 4.5-4.8 億 M365 商業基礎)= 營收貢獻仍是毛毛雨、但腹地極大
- **New Model System(Satya 親自畫)**:大腦與調度層分離 —— 智能路由把簡單任務切到**自研 SLM/開源**(成本極低)、難題才用 OpenAI 頂級模型 → ①主動降低 OpenAI 單一依賴 ②馴服推理成本守住軟體毛利
- **「發電廠 vs 電網」**:只包裝 OpenAI = 電力經銷商(利潤看上游臉色);Azure AI Foundry + 多模型路由 = 電網(價值在調度,發電廠會被淘汰、電網不會)。**微軟在賭:大模型終將貶值、可替換 —— Copilot 對模型的「不忠誠」恰是最深護城河**
- 兌現數據:微軟雲全年 $2,140 億、**~90% 來自非前沿模型公司**;商業 RPO +84% 至 **$6,780 億,剔除 OpenAI 仍 +25%,且所有季增全來自非前沿模型客戶**;OpenAI 佔 RPO 從年初 ~45% 快速稀釋;非 OpenAI bookings +7% → +18% 加速;下季 Azure 指引 45% cc
- (讀者 Charlie Ku 補充,KP 未反駁:電網比喻不完整 —— 真護城河是**工作入口生態**:Windows/M365/Teams/Entra/身分/資料權限,整間工廠本來就按微軟生態運作)

## 主題二|微軟 CapEx 真的降了嗎?—— 沒有,是會計重分類

- 標題「FY26 指引 $1,900 億 → $1,750 億」;CFO Amy Hood 原話:**「除使用壽命調整外,2026 日曆年 CapEx 投資預期完全不變」= 一分錢沒少花**
- 機制:FY27 起**數據中心/辦公樓估計壽命 15 → 25 年** → 12 年租約佔壽命比 80% → 48%,跌破 75% 門檻 → **融資租賃(計入 CapEx)轉經營租賃(計入 OpEx)** —— 減少的 $150 億全部來自分類轉變
- 市場看得懂但**需要這個藉口**(「花得沒更多,賺得還在加速」)= 心照不宣的妥協
- ⚠️ 衍生後果(對財報品質):**壽命拉長 = 建築年折舊下降 = 帳面毛利率被墊高** —— 空方「折舊淹沒毛利率」的數學會被會計面部分遮蔽,現金燒錢實質未變
- 戰略訊號:把壽命定 25 年 = 正式宣告 AI 基建是「跨世代基礎建設」(如電廠/高速公路)—— GPU 經濟壽命僅 3-5 年,但土地/電力/冷卻可以一直換芯運作。軍備競賽零降溫,只是帳單呈現得更體面

## 主題三|Meta 財報怎麼這麼爛?—— 爛在敘事,不在生意

- 帳面:EPS $6.18(預期 $7.14-7.22,miss ~13%)、營益率 40%+ → 31%、**FCF 從每季 $100-120 億暴跌至 $7.84 億**
- 剝開:廣告 +27-28%、DAP 健康、AI 改善廣告排序有實證;**扣 $36 億一次性(法律和解+裁員)後營業利潤逆勢 +9%**
- 市場定價的是**不確定性折價**:CapEx $1,300-1,450 億、費用 +55%;七月 Bloomberg 爆料「出租閒置算力」讓市場期待 AWS 式新收入線,**Zuckerberg 電話會親手掐死:「數不清的客戶捧現金想買,我們不賣,自己都不夠用」** → 「只有支出、沒有對等收入」的陣痛期延長
- 定價因子 = **對管理層判斷力的信任**(元宇宙押注過重 vs 移動轉型/Reels 證明自己,兩段記憶的加權平均);Zuck 看五年、市場看一季 —— 「你不給短期數字,市場就自己填一個更悲觀的」;**「沒有收據時,你不需要全額買單」**

## 主題四|亞馬遜財報好在哪?—— 全端架構成形

- EPS $5.75 vs 預期 $1.82,但含 **$534 億 Anthropic 持股公允價值上漲**(帳面浮盈入損益);剝掉後營業利潤 +43% 至 $275 億仍超預期
- **三個核心數字**:① **AWS +37% = 18 個季度最快**(年化 $1,690 億體量再加速),backlog $4,960 億,管理層:**產能缺到 2027** ② **AI 業務年化 $150 億 → $250 億**(單季跳 $100 億,三位數年增);Bedrock 六個月新客 > 上線前兩年總和、Q2 花費 > 以往所有季度加總 = 實驗 → 放量拐點;結構從賣算力(先前 60%+ IaaS)轉賣平台(Bedrock 佔比 ~9% → Q1 ~37% → 再上台階,進百億量級) ③ **自研晶片年化 $250 億** —— 絕大部分是內部轉移定價(Trainium/Inferentia/Graviton 賣給自家 AWS);**Jassy:若像 Nvidia 對外賣,等效營收 ~×2** = Google 之後第二個被驗證的自研 AI 晶片規模化案例
- **Bedrock 往上走(平台層)+ Trainium 往下扎(硬體層)= 全端成本結構性優於純 Nvidia 依賴者**;成本在降、營收品質在升
- 代價:**CapEx 指引上調 $2,200 億;TTM FCF −$76 億**(一年前 +$182 億);OCF +33% $1,610 億
- **Jassy 罕見回本公式**:伺服器/網路設備平均 **<3 年損益平衡**,壽命 5-6 年,多數 AI 合約 5 年+ → 後段 = 近乎純自由現金流。兩個前提:「平均值」(高端集群更苛刻)+ **利用率維持高位**(需求放緩則回本週期無情拉長)
