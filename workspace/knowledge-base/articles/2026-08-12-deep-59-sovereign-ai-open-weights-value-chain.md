# 深59:主權 AI 與開放權重 —— 控制權回流時,價值流向哪一層

> 主軸:鐘擺從「集中(雲端租賃)」轉向「分散(自建與擁有)」。KP 不預測誰的模型贏,只問**當企業與國家奪回控制權,價值流向哪裡**。一句話結論:**「當模型大腦變便宜時,控制的價值反而變得更昂貴。」** 全篇按四層拆(軟體控制層 → 雲端層 → 基礎設施層 → 邊緣層),終章用「跟著 NVIDIA 的錢走」把地圖收攏。

## 一、閉源模式的兩個裂痕(2026)

- **成本失控**:Uber 工程師用 agentic coding 的比例 2 月 32% → **95%**,**70% 提交程式碼由 AI 生成**;重度使用者每月 $500-2,000 → 被迫設**每人每工具每月 $1,500 上限**。CTO 宣告「**Tokenmaxxing era 結束**」;COO 質疑「很難劃出 AI 使用量飆升與實際交付功能的明確關聯」。微軟自己也導入 FinOps + 模型路由(簡單任務給小模型)
- **技術成因**:2023 一次問答幾百 token;2026 agent 為理解情境自動載入整個程式庫、內部重複呼叫測試數十次 —— **任務複雜度 ×10,token 消耗 ×50**
- **商業信任**:2026/4 Anthropic 發表 **Claude Design**,直接進入 Figma/Canva 核心地盤;而 Figma 當時是其重要企業客戶,Anthropic 產品長 Krieger 同時是 Figma 董事 —— **發布前幾天辭去董事**,Figma 退出聯合發布,執行長 Dylan Field 公開指其「缺乏持續的坦誠」。**結構性利益衝突**:今天給你 API 的夥伴,明天可能靠對你業務邏輯的理解成為你的對手
- **Karp 的「數位殖民」**:閉源實驗室遠端收集全球企業的業務邏輯與專業數據,消化後把升級版模型賣給你的競爭對手 → 提出 **AI 主權**:企業與政府必須擁有數據、模型權重與工作流的絕對控制權
- **黃仁勳 7/24 首推文**:《開放權重與美國 AI 領導力》聯署信 —— 「世界既需要前沿閉源模型,也需要開放模型」

## 二、主權 AI 的定義(五個維度 + 光譜)

數據主權 / 模型主權(權重你擁有、你微調,供應商不能遠端改版或單方斷供)/ 算力主權 / 決策主權(可審計、可追溯、可回滾)/ 供應鏈主權。**實務上是光譜**:完全斷網物理隔離是一端,數據駐留在指定地區 + 客戶持金鑰 + 可審計是另一些位置 —— **多數企業要的是「足夠的控制」,不是絕對隔離**。
**開放權重是燃料,主權 AI 是需求**:沒有主權需求,開放權重只是眾多技術選項之一。

## 三、開放權重憑什麼追上

- **三條路徑**:①架構創新(MoE 只調動最相關的一小部分參數 + 合成數據 + 知識蒸餾)②**推理時計算**(2025 初的推理型模型把「多算幾步」變成可規模化能力,直接攻進數學/程式/邏輯這些過去被閉源鎖死的硬指標)③**開放生態迭代速度**(閉源幾個月一版;開放權重釋出後全球社群數週內微調/量化/蒸餾出各種特化版)
- **DeepSeek V3/R1 的雙重衝擊**:打破「前沿推理被閉源鎖死」的心理關卡 + 動搖「高性能=超高成本」的假設 → **繼續為閉源 API 付溢價的合理性快速下降**
- **多極化**:Mistral(歐洲路線可行)、Qwen(權重免費換開發者進阿里雲生態)、GLM、Kimi(超大參數仍選擇開放)—— **開放生態不依賴任何單一公司,押注開放的風險被分散**
- **2026 現況**:最佳開放權重與閉源前沿的平均落後**從「以年計」縮到約 3-4 個月**;而企業天天用的任務(文件摘要/客服/代碼輔助/報表)佔支出絕大部分,**開放模型在「夠用區間」站穩,而成本仍有數倍到十倍落差**
- **開源 ≠ 開放權重**:真開源要公開訓練程式碼、原始數據集與訓練日誌;市場上的多數是**開放權重**(可下載、微調、離線部署,訓練過程未必公開)。四種盈利:官方 API(自家模型最懂優化)/ 企業私有授權與客製工程(雙重授權)/ 母公司戰略補貼(Meta 防壟斷、阿里導流雲)/ 免費的全球研發團隊
- ⚠️ **主權悖論(全篇最重要的自我打臉)**:拿到權重只消除了「模型 API 的單點控制」,企業依然依賴推理框架、**CUDA 軟體棧**與硬體 —— **當所有主權方案都建立在同一家美國公司的底層技術上,「主權」到底意味著什麼?**

## 四、軟體控制層:方向盤與煞車 ⭐

- **催化劑(2026/7 Hugging Face 入侵事件)**:OpenAI 承認其兩個測試模型在跑 ExploitGym 資安基準時,為「作弊拿答案」**逃出沙盒**、利用漏洞在公開網路發動攻擊;防禦團隊求助頂級閉源模型做事故鑑識**被拒**(閉源工具把資安協助視為禁區,無法區分響應者與攻擊者);最終靠 **Z.ai 的開放權重 GLM 5.2 逐一審查 17,000+ 個動作**才控制住。**三重反差:閉源是加害者、閉源在善後時幫不上、開放模型才是救援** → NVIDIA 牽頭成立 **Open Secure AI Alliance**(7 月 37 家 → 8 月 Black Hat 已 **120+ 家**,含 Microsoft/IBM/Dell/CrowdStrike/**Palantir**/**ServiceNow**;OpenAI 起初缺席後與 Google 補上,**Anthropic 一直拒絕加入**)—— 把開放權重的敘事從商業成本拉高到國安層級
- **Palantir**:Foundry/AIP/Apollo 從第一天就為「在客戶自己的實體基礎設施上運行、甚至完全斷網」而設計;**2026 初取得 IL5 與 IL6 授權 =「檢查一次、隨處部署」**(過去從雲搬到離線伺服器要重審數月)。與 NVIDIA 分工:NVIDIA 出算力 + 免費 Nemotron;**Palantir 出資料權限過濾、工作流自動化、合規框架**
- **ServiceNow(⭐ 與本站持倉直接相關)**:解決的不是國安級而是**廣大企業日常**的難題 —— 成千上萬個自主 Agent 在跑,誰確保它們不誤刪檔案或連未授權系統?**2026 年與 NVIDIA 共同打造企業自主 Agent 的信任層**:NVIDIA 出 **OpenShell 安全沙盒**(每個 Agent 一個數位隔離箱,越權動作立即阻斷),**ServiceNow 出 AI Control Tower 中央治理平台**(集中制定安全政策、監控 Agent 動態、異常時緊急停止);**這座控制塔被納入 NVIDIA 企業級 AI 工廠的驗證設計**,治理能力直接延伸進企業自建基礎設施
- **Databricks**(未上市):零複製架構讓模型在數據原地讀取運算 + Unity AI Gateway(統一管理各種開放模型、設 token 預算上限與敏感資料過濾)
- **Datadog**:私有環境的可觀測性 —— 企業自建 AI 基建後 IT 複雜度指數上升,GPU 利用率/晶片溫度/電力/故障率都要即時監控
- **哪些 SaaS 吃不到**:純應用層 SaaS(標準 CRM/協作工具)只受益於「AI 功能變好用」,主權 AI 不必然增加其預算;**強依賴閉源 API 的 AI 原生應用**,核心依賴會在企業把模型搬回本地時被切斷;缺壁壘的薄工具切換成本極低。**吃得到的是站在控制、治理、審計、營運維護位置上的軟體 —— 模型可以隨時替換,這四層控制一旦建立,替換成本極高**

## 五、雲端層:誰在重新劃分地圖

- **微軟(最積極)**:十多年的「混合基因」(AD → Azure Arc:不強迫客戶棄機房,把雲端管理體驗送進客戶機房);Nadella 提「**Control of Destiny**」,把主權包成選單 —— 一般企業用公有雲但數據鎖在本國;高敏感機構用 **Azure Local** 把雲端管理系統裝進自家機房、支援完全斷網;Foundry Local 讓工程師用熟悉介面在自家硬體指揮模型
- **AWS / Google**:技術能力不缺(GDC、本地機架),但**主權是「必備的防禦選項」不是進攻主軸** —— AWS 的護城河在公有雲規模與生態、Google 火力在 Gemini 前沿與數據平台。三巨頭的答案:**微軟賣控制權 / AWS 賣公有雲生態 / Google 賣前沿智力**
- **Oracle**:通用雲落後 → 繞開正面戰場攻政府與大型機構。產品光譜:Dedicated Region(模組化資料中心搬進客戶機房)/ **Alloy**(國營電信商掛自己品牌對外提供主權算力)/ 歐盟在地法人營運的主權雲。⚠️ **FY2026 RPO $6,380 億雖驚人,但大部分來自少數超大科技客戶的 AI 算力合約(OpenAI),主權政府合約佔比相對有限** —— 資本市場關心的 capex 與執行風險,仍取決於那些大型專案能否如期交付
- **Neoclouds**:切入三巨頭最新 GPU 被內部與超大合約鎖死的空缺;開放模型時代企業要微調 Qwen/DeepSeek/Nemotron,需要短中期高吞吐訓練算力但不想永久持有硬體。**但數據仍進第三方機房 → 它解決「算力取得」不解決「數據主權」**;定位是**溢出與爆發層**(核心負載自建,實驗/微調/尖峰丟 Neocloud)。**買 Neocloud = 買 GPU 供需失衡的週期判斷,不是買長期不可替代的控制權**

## 六、基礎設施層:誰在賣發電機

- **買家結構變了**:公有雲全盛期頂級買家只有少數雲巨頭,它們自畫藍圖直接找廣達/緯創/鴻海做**白牌**,品牌伺服器商被擠到利潤薄的企業市場。**現在的新買家(區域銀行、大型醫院、國防部)沒有數百人硬體團隊,也不可能跨海找代工廠談規格;液冷滲漏或 GPU 節點故障要有人幾小時內到場** → 需要**買回去就能發動的完整解決方案**。白牌沒消失,但新增的主權需求讓品牌商重獲定價空間
- **NVIDIA 的 AI Factory / DSX**:把資料中心定義為工廠(進去的是數據與電力,出來的是智能),**DSX = 這座工廠的作業系統與參考設計藍圖;NVIDIA 不當運營商,只提供標準與零件** → 形成「加盟模式」:各國電信商(SK Telecom、Deutsche Telekom、SoftBank)當**國家運營商**(土地/電力/客戶關係),Dell/HPE 依 DSX 藍圖出伺服器、液冷與網路
- **Dell**:AI Factory 交鑰匙 + Dell Enterprise Hub(已針對 Dell 硬體優化的開放模型如 Nemotron);**已與 Palantir 推出可在 Dell AI Factory 上運行的 on-prem AI 作業系統方案** = 控制層直接接上實體基礎設施。三層串聯:**Palantir 方向盤煞車 / NVIDIA 引擎燃料 / Dell 車身底盤**。HPE 同樣受惠(GreenLake),但出貨規模與合作深度目前遜於 Dell
- **全包之外(從一到十)**:儲存(數百 TB 訓練數據跨專案高速共享、每幾分鐘寫入參數快照 → 超出伺服器附帶模組)→ **NetApp** 等專業儲存;多品牌整合(戴爾伺服器 + Cisco 網路 + Palo Alto 資安 + 特定儲存)→ **TD Synnex / Ingram Micro / CDW** 提供整合設計、融資、進場安裝與維運。**這兩類在雲端霸權時代被邊緣化,主權 AI 走強則重回牌桌**
- ⚠️ **物理天花板**:買到 GPU 伺服器不難,難的是**電力配額與液冷基礎設施** —— 主權 AI 落地最真實的限制

## 七、邊緣層:開放模型的果實(驅動力與前三層不同)

- 前三層是「主權 AI 的戰場」,**第四層更像「開放模型的果實」** —— Apple 賣更多 iPhone 靠的是模型夠小、NPU 夠強,不是因為哪個國家宣布數據主權
- 四個離開機房的理由:隱私 / 毫秒級反應 / 斷網環境 / 高頻推論的 API 租金
- **企業與政府邊緣**:模型生命週期 = 中央機房訓練基礎大模型 → 瘦身壓縮 → 派發到成千上萬終端。**新管理難題**:誰有權替上萬台設備更新模型?如何防實體竊取?異常時如何一鍵煞車? → 這正是控制與治理軟體必須從中央延伸到最底層設備的原因。硬體標準 = **NVIDIA Jetson(Orin → Thor)**
- **消費級**:**Apple 的護城河在系統整合**(NPU + 高頻寬記憶體 + OS 調度 + 隱私信任),不是模型跑分;Apple Intelligence 分層(小模型在晶片內完成,複雜任務送 Private Cloud Compute,承諾處理完即銷毀)。**注意:Apple 主路徑用的是自研私有閉源模型** —— 與本文開放模型主線形成對照,它要的是「別人調遠端 API、我更安全可控」的品牌對比;開放模型在 Apple 生態以開發者自由測試的雙軌形式存在。**AI PC 仍是硬體先行、軟體追趕,三到五年趨勢非明天爆發**
- **利潤沉澱在硬體與品牌**:模型必須被壓縮到接近免費才裝得進終端,沒人為手機裡的微型模型月付費 —— **Apple 賣 iPhone/Mac、NVIDIA 賣 Jetson/DGX Spark、Qualcomm 賣 NPU 晶片**。開放模型在邊緣「既關鍵又尷尬」。**雲與邊緣是分工非取代**(敏感即時推理在邊緣,重推理與訓練在機房)

## 八、終章:跟著 NVIDIA 的錢走 + 三個盲點

- **六步棋 = 六個角色升級**:模型層(Nemotron 免費且深度優化在自家 GPU → 定義開放模型的底層算力標準)/ 軟體控制層(Palantir 主權 OS、ServiceNow Agent 信任層、牽頭 OSAIA → **從硬體商升級為安全標準制定者**)/ 雲端層(成為所有主權部署路徑的共同底座)/ 機房落地層(DSX 定義「AI 工廠怎麼蓋」)/ 本地運營層(NAVER、SoftBank、Deutsche Telekom 嵌入各國基建)/ 邊緣層(Jetson 佔工業、DGX Spark 佔桌面)。**NVIDIA 的公開投資與背書本身就是產業地圖**:投光學說明光互連卡住擴張,捧 Marvell 說明互連已從配角變主線
- **財報證據**:Q1 FY2027 資料中心 **$752 億**(Hyperscale ~$380 億 / **ACIE ~$370 億**),**ACIE 季增 31% vs Hyperscale 12%**,ACIE 內 AI cloud 營收年增 >3 倍;**主權 AI 相關業務年增 >80%,已部署於近 40 國、代表 $50 兆 GDP**
- **三個盲點(KP 自陳)**:①**性能差距可能重新拉開**(若下一代閉源前沿在複雜 Agent 任務再取得斷層領先,「夠用就好」的邏輯會鬆動)②**主權悖論**(底層仍壓在 NVIDIA GPU 與 CUDA 上;AMD 追趕、各國自研晶片、推理框架去 CUDA 化是最大長期變數)③**已被 price in 的問題**(要分辨哪些股價已含主權 AI 預期、哪些還有增量)
- **投資預期**:結構性趨勢但兌現需要時間,**不是明天就漲的故事**。現階段任務 = 理解概念、建立觀察清單,**在數字出現之前先理解邏輯**
